About this map

This map shows the trails, points of interest, and scenic overlooks and their viewsheds in High Cliff State Park. This map is intended for people planning to visit or currently visiting the park. This map will help with trip planning and navigation within the park. There is no existing interactive web map for this park and the trails and it is important to provide this service to park visitors as it is easier to navigate and use than a static map.

Methodology

  • major processesing steps
  • The static park map was brought into ArcGIS Pro and georeferenced and points of interest such as bathrooms, scenic overlooks, and parking lots were manually digitized.
  • The trail lines were dissolved, so that each trail was represented by only one line and all fields excpet name, mileage, and usage were deleted.
  • The slope data was derived by using the DEM and the trail line data. The trail lines were split into 5 foot segments using the "Generate Points Along Lines" and "Split Line at Points" tools in ArcGIS Pro. The DEM data was then added to each segment using the "Add Surface Information" tool using the average slope.
  • The viewsheds were calculated using the scenic overlook points and the DEM. First, the "Observer Points" tool was used to determine the areas visibile from each overlook, then the "Minimum Bounding Geometry" tool was used to encompass the pixels visible to produce a single polygon of visible area for each viewpoint.
  • Feature classes were exported from ArcGIS Pro using the "Feature to JSON" tool, checking the boxes to Output to GeoJSON and to reproject to WGS84. Within the coding software, a variable name was added to the data and the file was changed from .geojson to .js and the data was then added to the map.

Project Summary and Credits

  • Strengths:
    - The legends that automatically hide when the layer is not visible on the map reduces visual clutter and enables users to focus on the information they wish to see
    - The ability to get the real-time location of the user will be useful for people who are actively in the park and navigating
    - Overall, the webpage works quickly and reacts fast, even with the size of data integrated
    - The map frame is still the main focus of the page, not getting diminished by the side panel, layer controls, or mini map
  • Limitations:
    - Some of the main attractions such as the Cheif Red Bird Statue and Lime Kiln Ruins are not documented on this map
    - Some of the data files can be quite large (e.g., the trail slope data). This could slow down performance when trying to load this data in
    - The viewshed polygons only account for the DEM segments that included area within the park boundary and may not be completely accurate to what all can be seen
    - The view shed polygons were also created using the minimum bounding geometry to encompass the raster pixels and could be an overestimation to what can be seen
  • Next steps for final submission:
    1. Determine how to distinguish individual trails while still categorizing by usage
    2. Add details to trail popups
    3. Improve styling of viewshed polygons
