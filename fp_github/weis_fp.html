High Cliff State Park GEO 455: Webmapping
Map Layers and Controls

This map is intended to use for navigation and trip planning to High Cliff State Park.

  • Use the layer control to toggle layers on and off.
  • Hover over a trail to highlight it.
  • Click the info button on the map for addional map informtion
  • Click the home button on the map to return to the original view
  • Click the location button on the map to see real-time location for in-park navigation
